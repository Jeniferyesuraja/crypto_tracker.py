# Crypto Tracker

Python script to scrape top cryptocurrency data (price, 24h change, market cap) and save it with timestamps.

## Features
- Scrapes top coins data using Selenium
- Saves data to CSV with timestamp
- Dashboard to view tracked data

## Requirements
pip install selenium

## Usage
python crypto_tracker.py

## Files
- `crypto_tracker.py` - Main scraper script
- `dashboard.py` - Dashboard for viewing data
- `crypto_history.csv` - Saved historical data
